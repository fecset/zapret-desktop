# Zapret Desktop

![Значок Zapret Desktop](src/Zapret.Desktop/Assets/app.png)

**Окно управления Zapret для Windows.** Выбирайте стратегию, смотрите состояние процесса и службы, редактируйте списки и читайте логи в одном приложении.

`Windows 10/11 x64` · `.NET 10` · `Avalonia 12`

Zapret Desktop — проект [fecset](https://github.com/fecset/zapret-desktop). Сетевой движок и стратегии взяты из [Windows-дистрибутива Flowseal](https://github.com/Flowseal/zapret-discord-youtube), основанного на [zapret от bol-van](https://github.com/bol-van/zapret). Интерфейс не заменяет эти компоненты: он управляет их запуском и показывает результат.

## ▶️ Первый запуск

1. Откройте [Releases](https://github.com/fecset/zapret-desktop/releases) и скачайте архив для Windows x64.
2. Распакуйте его целиком в отдельную папку. `Zapret.Desktop.exe` должен оставаться рядом с папкой `zapret`.
3. Запустите EXE и подтвердите запрос прав администратора.
4. На главной странице выберите стратегию и нажмите «Запустить Zapret».

Готовый архив содержит .NET, поэтому отдельная установка среды выполнения не нужна. Если вы только знакомитесь с приложением, начните с главной страницы: там видны выбранная стратегия, состояние движка, драйвера WinDivert и службы Windows.

## 🧩 Как устроено управление

```text
Окно / трей → выбранная стратегия + списки → winws.exe → WinDivert
                   └─ служба Windows (если установлена)
```

- **Обычный запуск** привязан к текущему экземпляру приложения. Выход через трей останавливает запущенный им `winws.exe`.
- **Служба Windows** запускает Zapret отдельно и может продолжать работать после закрытия окна. Управление службой находится в «Настройках».
- **Внешний запуск** означает, что обнаружен `winws.exe`, которым приложение не управляет. Останавливайте его там, где он был запущен.
- **Выбор стратегии** сохраняется для следующего запуска. Уже работающий процесс не меняет параметры, пока вы его не перезапустите.

В трее показаны текущий статус и выбранная стратегия. Команды «Запустить» и «Остановить» доступны по состоянию процесса.

## 🗂️ Где искать нужное

| Задача | Раздел |
| --- | --- |
| Запустить или остановить Zapret, увидеть состояние компонентов | Главная |
| Выбрать `general*.bat` или сравнить стратегии тестом | Стратегии |
| Просмотреть и изменить домены или IP-адреса в конкретном файле | Списки |
| Проверить файлы, права, драйвер и службу | Диагностика |
| Посмотреть события и ошибки, начиная с последних | Логи |
| Настроить службу, фильтры, запуск вместе с Windows и тему | Настройки |

Автоподбор использует тестовый скрипт из дистрибутива Flowseal. Перед тестом остановите работающий `winws.exe` и службу Zapret. Результат теста — рекомендация: стратегию для постоянного использования вы выбираете сами.

## 💾 Файлы и пользовательские данные

Приложение читает `zapret/bin`, `zapret/lists`, `zapret/utils`, `service.bat` и файлы `general*.bat`. При редактировании списка меняется выбранный файл в `zapret/lists`; перед заменой дистрибутива сохраните свои записи. Настройки интерфейса находятся в `%LOCALAPPDATA%\ZapretDesktop\settings.json`.

Если стратегия не запускается, начните с «Логов», затем запустите «Диагностику». Она помогает различить отсутствие файлов, недостаточные права и проблемы со службой или драйвером. Драйвер WinDivert иногда остаётся загруженным после остановки Zapret — это отдельно показано на главной странице.

## 🛠️ Сборка проекта

Понадобятся Windows x64 и .NET 10 SDK. Папка `zapret` должна сохранять структуру дистрибутива, включённого в репозиторий.

```powershell
dotnet restore ZapretDesktop.slnx
dotnet build ZapretDesktop.slnx -c Release
dotnet test ZapretDesktop.slnx -c Release
```

Для локального запуска используйте `dotnet run --project src/Zapret.Desktop/Zapret.Desktop.csproj`. Устройство решения кратко описано в [ARCHITECTURE.md](ARCHITECTURE.md).

### 📦 Подготовка релиза

```powershell
dotnet restore src/Zapret.Desktop/Zapret.Desktop.csproj -r win-x64
dotnet publish src/Zapret.Desktop/Zapret.Desktop.csproj -p:PublishProfile=WinX64 -o dist/ZapretDesktop-win-x64 --no-restore
```

Профиль создаёт автономный набор файлов для Windows x64 без отладочных `.pdb`. Для релиза нужен **весь каталог публикации**, включая `zapret`, лицензии и библиотеки. Перед упаковкой просмотрите `dist/ZapretDesktop-win-x64/zapret/lists`: туда могут попасть ваши локальные домены и IP-адреса.

```powershell
Compress-Archive -Path dist/ZapretDesktop-win-x64/* -DestinationPath dist/ZapretDesktop-win-x64.zip -Force
```

В поле **Assets** нового GitHub Release загрузите именно `dist/ZapretDesktop-win-x64.zip`. Файлы `src/`, `tests/`, `.vs/` и отдельный `Zapret.Desktop.exe` туда добавлять не нужно: нужный EXE уже лежит внутри ZIP вместе с зависимостями. GitHub также создаёт архив исходного кода из коммита релиза. Сам каталог `dist/` не хранится в Git.
