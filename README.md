# ![Значок Zapret Desktop](src/Zapret.Desktop/Assets/app-32.png) Zapret Desktop

**Приложение для управления Zapret на Windows:** запуск, выбор и проверка стратегий, редактирование списков и обновления.

`Windows 10/11 x64` · `v0.2.2`

Использует движок и стратегии из [дистрибутива Flowseal](https://github.com/Flowseal/zapret-discord-youtube), основанного на [zapret от bol-van](https://github.com/bol-van/zapret).

## 🖥️ Интерфейс

![Главная страница Zapret Desktop](UI.png)

## ▶️ Установка и запуск

1. Скачайте ZIP для Windows x64 из [Releases](https://github.com/fecset/zapret-desktop/releases/latest).
2. Распакуйте архив целиком в отдельную папку. Оставьте `Zapret.Desktop.exe` рядом с папкой `zapret`.
3. Запустите `Zapret.Desktop.exe` и подтвердите запрос прав администратора.
4. Выберите стратегию на главной странице и нажмите «Запустить Zapret».

Устанавливать .NET отдельно не требуется. Подходящая стратегия зависит от провайдера: если соединение не работает, попробуйте другую или запустите автоподбор.

## 🗂️ Возможности

| Раздел | Возможности |
| --- | --- |
| Главная | Запуск и остановка Zapret, состояние движка, драйвера и службы, проверка YouTube и Discord |
| Стратегии | Выбор стратегии, автоподбор и история результатов |
| Списки | Просмотр и редактирование доменов и IP-адресов |
| Диагностика | Проверка файлов, службы, драйвера, DNS, hosts и возможных конфликтов |
| Логи | Журнал действий и ошибок |
| Настройки | Фильтры, служба Windows, автозапуск, тема, резервные копии, IPSet, hosts, payload и обновления |

Перед автоподбором остановите Zapret и удалите службу Zapret в «Настройках», если она установлена. На время теста списки и диагностика недоступны.

После изменения списков или фильтров перезапустите Zapret, чтобы применить изменения.

Для полного выхода используйте меню значка в трее → «Выход». Это останавливает движок, запущенный Desktop. Установленная служба Windows работает независимо от приложения.

Чтобы Desktop и выбранная стратегия запускались при входе в Windows, включите «Запускать приложение вместе с Windows» и «Запускать Zapret при открытии приложения» в настройках. Для запуска Zapret до входа пользователя используйте службу Windows.

## 💾 Данные и обновление

Пользовательские списки находятся в `zapret/lists`, а настройки, история и резервные копии — в `%LOCALAPPDATA%\ZapretDesktop`.

Перед ручным обновлением откройте «Настройки → Резервные копии и перенос данных», нажмите «Экспорт ZIP» и сохраните архив вне папки приложения. Закройте Desktop через трей и остановите службу, если она используется. Распакуйте новую версию в отдельную папку и перенесите данные через «Импорт ZIP».

Обновления Desktop и движка также доступны в «Настройках». После установки обновления Desktop запустите новую версию вручную.

Подробности переноса и восстановления данных — в [инструкции пользователя](docs/README-release.md).

## 🔧 Если что-то не работает

Откройте «Логи» и запустите «Диагностику». Если проблема остаётся, создайте [issue](https://github.com/fecset/zapret-desktop/issues), указав версию Desktop, версию Windows, действия перед ошибкой и относящиеся к ней строки журнала.

Проверка доступности YouTube и Discord не проверяет воспроизведение видео и голосовую связь. Если сайт открывается, а видео или звонки не работают, попробуйте другую стратегию.

## 🛠️ Сборка из исходников

Понадобятся Windows x64 и .NET 10 SDK.

```powershell
dotnet restore ZapretDesktop.slnx
dotnet build ZapretDesktop.slnx -c Release
dotnet test ZapretDesktop.slnx -c Release
```

Запуск приложения:

```powershell
dotnet run --project src/Zapret.Desktop/Zapret.Desktop.csproj
```

Сборка ZIP: `./scripts/Build-Release.ps1`. Устройство проекта описано в [ARCHITECTURE.md](ARCHITECTURE.md).
