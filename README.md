# ![Значок Zapret Desktop](src/Zapret.Desktop/Assets/app-32.png) Zapret Desktop

**Декстопное приложение для управления Zapret на Windows.** Выбирайте стратегию, проверяйте доступность сервисов, редактируйте списки, сохраняйте резервные копии и устанавливайте обновления в одном приложении.

`Windows 10/11 x64` · `.NET 10` · `Avalonia 12` · `v0.2.2`

Zapret Desktop — проект [fecset](https://github.com/fecset/zapret-desktop). Сетевой движок и стратегии взяты из [Windows-дистрибутива Flowseal](https://github.com/Flowseal/zapret-discord-youtube), основанного на [zapret от bol-van](https://github.com/bol-van/zapret). Интерфейс не заменяет эти компоненты: он управляет их запуском и показывает результат.

## ▶️ Первый запуск

1. Откройте [Releases](https://github.com/fecset/zapret-desktop/releases) и скачайте архив для Windows x64.
2. Распакуйте его целиком в отдельную папку. `Zapret.Desktop.exe` должен оставаться рядом с папкой `zapret`.
3. Запустите EXE и подтвердите запрос прав администратора.
4. На главной странице выберите стратегию и нажмите «Запустить Zapret».

Готовый архив содержит .NET, поэтому отдельная установка среды выполнения не нужна.

## 🧩 Как устроено управление

- **Обычный запуск** привязан к текущему экземпляру приложения. Выход через трей останавливает запущенный им `winws.exe`.
- **Служба Windows** запускает Zapret отдельно и может продолжать работать после закрытия окна. Управление службой находится в «Настройках».
- **Внешний запуск** означает, что обнаружен `winws.exe`, которым приложение не управляет. Останавливайте его там, где он был запущен.
- **Выбор стратегии** сохраняется для следующего запуска. Кнопка «Применить выбор и перезапустить» применяет выбранную стратегию и текущие фильтры к процессу или службе.

Запуск и перезапуск службы из настроек применяют выбранную стратегию и текущие диапазоны Game Filter. Перед установкой или запуском службы остановите обычный Zapret; внешний `winws.exe` остановите в приложении, которое его запустило.

В трее показаны текущий статус и выбранная стратегия.

Поля в «Настройках» сохраняются явно: «Сохранить фильтры» применяет режимы и порты, а «Применить и перезапустить Zapret» сначала проверяет и сохраняет видимые значения, затем перезапускает движок. Настройки приложения сохраняются отдельной кнопкой. Несохранённый ввод сохраняется при переходах между страницами и обновлении zapret; импорт и восстановление заменяют его данными выбранной копии.

Во время долгой операции рядом с подписью кнопки вращается индикатор, повторное нажатие временно недоступно. Статус сохраняется при переходах между страницами; после завершения, ошибки или отмены кнопка возвращается к обычному виду. Отмена автоподбора и загрузки остаётся доступной, а ожидание контрольного HTTPS-запроса не блокирует остановку Zapret.

## 🗂️ Где искать нужное

| Задача | Раздел |
| --- | --- |
| Запустить или остановить Zapret, увидеть состояние компонентов | Главная |
| Выбрать `general*.bat`, сравнить стратегии тестом, открыть историю и применить рекомендацию | Стратегии |
| Просмотреть и изменить домены или IP-адреса в конкретном файле | Списки |
| Проверить файлы, права, драйвер, службу, DNS, hosts, proxy и возможные конфликты | Диагностика |
| Посмотреть события и ошибки | Логи |
| Настроить службу, фильтры, автозапуск и тему; резервные копии, payload и обновления | Настройки |

Автоподбор использует адаптированный скрипт Flowseal, встроенный в приложение. Обновление дистрибутива zapret не заменяет этот скрипт. Стратегии и цели проверки читаются из текущей папки `zapret`. Перед тестом остановите работающий `winws.exe` и удалите службу Zapret. Завершённые и отменённые запуски сохраняются в истории вместе со счётчиками и подробным отчётом. Кнопка «Применить рекомендацию» сохраняет выбор для следующего запуска.

Пока идёт автоподбор, диагностика и работа со списками временно недоступны: тест управляет движком и меняет IPSet. На этих страницах показана причина и переход к отмене теста. Заблокированные действия не ждут в скрытой очереди; после завершения список загружается снова.

На главной странице проверка HTTP/TLS YouTube и Discord показывает результат и время отдельно от состояния `winws`. Проверка сети не блокирует остановку, перезапуск или выбор стратегии; после остановки её устаревший результат не отображается. Успешный HTTP-ответ не подтверждает воспроизведение видео или работу Discord voice.

Автоматическую проверку доступности после запуска Zapret можно отключить в «Настройках»; ручная проверка остаётся доступной. Проверка версий при открытии настраивается отдельно. Страница выпуска открывается только кнопкой «Открыть выпуск», после проверки браузер автоматически не запускается.

При выходе во время автоподбора Desktop отменяет тест, дожидается остановки PowerShell и восстанавливает исходный IPSet. После прерванного запуска теста восстановление также выполняется при следующем открытии приложения, до автоматического запуска Zapret. Если тестовая копия IPSet отсутствует, запуск блокируется: в «Настройках → Резервные копии и перенос данных» выберите исправную копию или импортируйте ZIP и подтвердите восстановление. Восстанавливаются сохранённые в архиве данные; пустые пользовательские списки не очищают текущие записи. Новая копия при восстановлении автоматически не создаётся. До успешного восстановления маркер сбоя остаётся на диске. Выйти можно после остановки процессов, принадлежащих Desktop; независимая служба продолжает работать.

Чтобы Desktop и выбранная стратегия запускались автоматически при входе в Windows, в «Настройках» включите «Запускать приложение вместе с Windows» и «Запускать Zapret при открытии приложения», затем сохраните настройки. Desktop создаёт задачу Планировщика для текущего пользователя с повышенными правами. При первом запуске версии 0.1.3 старая запись автозагрузки переносится автоматически; отдельная настройка запуска стратегии сохраняется. Для запуска Zapret до входа пользователя установите службу Windows.

## 💾 Файлы и пользовательские данные

Приложение читает `zapret/bin`, `zapret/lists`, `zapret/utils`, `service.bat` и файлы `general*.bat`. При редактировании списка меняется выбранный файл в `zapret/lists`. Настройки, история, резервные копии и сохранённые оригиналы payload находятся в `%LOCALAPPDATA%\ZapretDesktop`.

В «Настройках» можно создать копию, экспортировать пользовательские данные в ZIP, импортировать ZIP и восстановить выбранную копию. Архив включает настройки, поддерживаемые списки, фильтры и два ACTIVE payload. Перед важными изменениями автоматически сохраняется отличающееся состояние; обычное сохранение настроек, неверный ввод и сохранение без изменений копию не создают. Хранятся до 10 новых автокопий, а ручные и уже существовавшие архивы не удаляются. Импорт и восстановление не создают новые архивы. При необходимости сначала сохраните текущее состояние кнопкой «Создать копию». Отсутствующие файлы и свойства настроек сохраняются; пустые пользовательские списки из архива не стирают текущие записи. История содержит последние 100 тестов. Импорт не включает автозапуск Windows без отдельного действия пользователя.

Перед первой заменой ACTIVE payload сохраняется исходный файл. После замены появляются кнопки «Отменить замену для Discord» и «Отменить замену для игр»: они возвращают сохранённый файл и показываются только при наличии изменённого файла и его исходной копии. Сначала остановите Zapret и службу, а после отмены перезапустите стратегию. Для файлов, изменённых до версии 0.2.0, исходной копии может не быть.

Обновления сначала загружаются и проверяются, затем устанавливаются отдельной кнопкой. ZIP сверяется с SHA-256 GitHub, проверяются пути, размер, исполняемые файлы и стратегии. Upstream обновляется с копией прежнего каталога и откатом в текущем сеансе; редактируемые списки и payload сохраняются. Desktop обновляет отдельный помощник после закрытия приложения; прежний каталог остаётся рядом с установкой. Запустите новую версию вручную после завершения установки. Пути резервной копии и журнала показаны в логах. Восстановление копии, обновление программы и применение IPSet требуют остановленного движка и службы.

IPSet загружается из фиксированного источника Flowseal и сохраняет текущий режим фильтра. «Показать изменения hosts» загружает адреса из проекта zapret и показывает текущий и предлагаемый текст, оставляя системный файл без изменений. «Применить изменения hosts» записывает показанные адреса, сохраняет копию текущего файла и обновляет диагностику. Требуются права администратора и остановленный движок/служба. Альтернативные адреса сайтов сами по себе не считаются ошибкой; локальные и нулевые адреса остаются ошибками блокировки. Чужие строки hosts сохраняются. Диагностика системные файлы не изменяет.

Если стратегия не запускается, начните с «Логов», затем запустите «Диагностику». Она помогает различить отсутствие файлов, недостаточные права и проблемы со службой или драйвером. Драйвер WinDivert иногда остаётся загруженным после остановки Zapret — это отдельно показано на главной странице.

Предупреждение о перезапуске фильтров появляется после сохранения изменённых параметров для работающего движка и исчезает после успешного перезапуска или остановки. В предпросмотре hosts показываются числа добавляемых и удаляемых сопоставлений; сравнение текста доступно по раскрытию. Если изменений нет, повторная запись и создание копии hosts пропускаются.

Во время загрузки и проверки обновлений, IPSet или hosts можно остановить Zapret и отменить подготовку. Установка подготовленных файлов выполняется отдельным действием после остановки движка и службы.

## 🛠️ Сборка проекта

Понадобятся Windows x64 и .NET 10 SDK. Папка `zapret` должна сохранять структуру дистрибутива, включённого в репозиторий.

```powershell
dotnet restore ZapretDesktop.slnx
dotnet build ZapretDesktop.slnx -c Release
dotnet test ZapretDesktop.slnx -c Release
```

Для локального запуска используйте `dotnet run --project src/Zapret.Desktop/Zapret.Desktop.csproj`. Устройство решения кратко описано в [ARCHITECTURE.md](ARCHITECTURE.md).

Для релизного ZIP выполните `./scripts/Build-Release.ps1`. Скрипт запускает тесты, публикует автономный EXE, собирает только необходимые файлы движка, добавляет описание изменений и лицензии, проверяет структуру и выводит SHA-256 архива. В ZIP включается отдельная [инструкция для пользователя](docs/README-release.md) под именем README.md. Временная сборка создаётся в системном временном каталоге и удаляется после упаковки. Архив публикуется в GitHub Releases вручную; отдельный файл SHA-256 прикладывать необязательно.
