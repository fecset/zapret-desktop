# ⚡ Zapret Desktop

Графическое приложение для Windows 10/11 x64, которое управляет [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube). Интерфейс написан на C#/.NET 10 и Avalonia 12. Сам Zapret, стратегии, `winws.exe` и WinDivert принадлежат исходным проектам; Zapret Desktop не реализует фильтрацию трафика самостоятельно.

> [!IMPORTANT]
> Это отдельный интерфейс от [fecset](https://github.com/fecset/zapret-desktop), а не официальный выпуск bol-van или Flowseal. Для запуска стратегий и управления службой требуются права администратора.

## 🚀 Как установить

1. Скачайте ZIP-архив со [страницы релизов Zapret Desktop](https://github.com/fecset/zapret-desktop/releases).
2. Распакуйте **весь архив** в отдельную папку.
3. Запустите `Zapret.Desktop.exe` и подтвердите запрос Windows на запуск от имени администратора.
4. Выберите стратегию на главной странице или в разделе «Стратегии», затем нажмите «Запустить Zapret».

Приложение использует значок в системном трее. Закрытие окна может свернуть его в трей — поведение выбирается в настройках. Команда «Выход из приложения» в трее останавливает `winws.exe`, запущенный этим экземпляром приложения. Отдельно установленная служба Windows продолжит работать, пока вы не остановите или не удалите её.

> [!NOTE]
> WinDivert — драйвер для перехвата сетевых пакетов. Антивирус может пометить его как инструмент повышенного риска. Загружайте сборку из проверенного источника и сверяйте её состав с исходниками; описание WinDivert есть в [репозитории разработчика](https://github.com/basil00/WinDivert).

## 🧭 Что есть в приложении

| Раздел | Возможности |
| --- | --- |
| 🏠 Главная | Запуск и остановка Zapret, текущие состояния движка, драйвера и службы, стратегия для следующего запуска. |
| 🧩 Стратегии | Выбор `general*.bat` и автоподбор с показом результата проверенных стратегий. |
| 📋 Списки | Просмотр, поиск, добавление и удаление доменов и IP-адресов в выбранном файле. |
| 🩺 Диагностика | Проверка файлов, прав, службы и компонентов, необходимых для работы. |
| 📜 Логи | История событий. |
| ⚙️ Настройки | Управление службой, фильтрами, автозапуском и темой. |

В трее отображаются статус Zapret и выбранная стратегия.

## ❓ Если что-то не работает

- **Нет стратегий или файлов:** проверьте, что рядом с EXE находится папка `zapret` с `bin`, `lists`, `utils`, `service.bat` и `general*.bat`.
- **Стратегия сразу останавливается:** откройте «Логи» и «Диагностика», проверьте права администратора, BFE и файлы WinDivert.
- **Сайт или приложение не открывается:** попробуйте другую стратегию и проверьте, есть ли нужный домен или IP-адрес в списках. Работоспособность стратегий зависит от сети и со временем меняется.
- **Zapret запущен вне приложения:** обычная кнопка остановки не завершает чужой процесс. Проверьте установленную службу или другие запущенные экземпляры.
- **Нужно обновить Zapret:** сначала сохраните свои списки и настройки. Обновляйте папку `zapret` только из [официальных выпусков Flowseal](https://github.com/Flowseal/zapret-discord-youtube/releases). Приложение проверяет наличие обновлений, но не скачивает и не запускает новые .bat автоматически.

## 🛠️ Сборка из исходников

Нужны Windows 10/11 x64 и .NET 10 SDK. В корне проекта должна быть папка `zapret` с дистрибутивом Flowseal и сохранённой структурой файлов.

```powershell
dotnet restore ZapretDesktop.slnx
dotnet build ZapretDesktop.slnx
dotnet test ZapretDesktop.slnx
dotnet run --project src/Zapret.Desktop/Zapret.Desktop.csproj
```

Настройки пользователя хранятся в `%LOCALAPPDATA%\ZapretDesktop\settings.json`. Приложение ищет папку `zapret` рядом со своим EXE или выше по дереву каталогов. Краткое описание устройства проекта находится в [ARCHITECTURE.md](ARCHITECTURE.md).
