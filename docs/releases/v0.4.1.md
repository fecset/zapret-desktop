# Zapret Desktop 0.4.1

- После успешного обновления Desktop автоматически удаляются служебная папка `ZapretDesktop-update-*` в `C:\Program Files` и распакованный пакет обновления.
- После обновления zapret удаляется использованный распакованный пакет. Резервная копия для отката сохраняется.
- Ошибка очистки не отменяет установленное обновление: приложение сообщает о проблеме и сохраняет журнал. При ошибке установки временные файлы остаются для диагностики.

## Обновление

Откройте «Настройки → Обновления» и обновите Zapret Desktop.

Очистка работает для обновлений, запускаемых из версии 0.4.1 и новее. Переход с 0.4.0 выполняет установщик старой версии, поэтому его временная папка и ранее накопившиеся папки автоматически не удаляются.

Для ручной установки скачайте `ZapretDesktop-v0.4.1-win-x64.zip` и распакуйте архив целиком. Перед заменой старой версии экспортируйте пользовательские данные через «Настройки → Резервные копии и перенос данных» и закройте приложение через меню трея → «Выход».

Windows 10/11 x64. Устанавливать .NET отдельно не требуется.

## Проверка

530 автотестов в конфигурации Release. Проверены успешное обновление настоящим PowerShell-установщиком во временной папке, очистка обоих форматов ZIP, сохранение пользовательских данных и отката, ошибки установки и очистки.
