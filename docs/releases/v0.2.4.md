# Zapret Desktop 0.2.4

- Обновления zapret и приложения получили текстовые кнопки с явным предупреждением об остановке Zapret и перезапуске Desktop.
- Для каждого компонента есть отдельная кнопка «Что нового». Исправлены отступы, контраст текста в тёмной теме и повторяющиеся сообщения об установленной версии.
- Обновление Desktop из этой версии сохраняет установленный дистрибутив zapret целиком, независимо от версии zapret внутри нового ZIP.
- При обновлении zapret заново формируется команда установленной службы Windows, чтобы она использовала параметры новой стратегии.
- Установщик Desktop сохраняет результат для показа при следующем запуске и пытается снова открыть приложение при ошибке установки. Исправлена кодировка скрипта для Windows PowerShell 5.1.
- Этап проверки SHA-256 называется «Проверка целостности».

## Обновление

В установленном приложении откройте «Настройки → Обновления», проверьте новые версии и нажмите кнопку обновления Zapret Desktop.

Переход на 0.2.4 выполняет установщик уже установленной версии. Исправления самого установщика из 0.2.4 будут действовать при последующих обновлениях.

Для ручной установки скачайте `ZapretDesktop-v0.2.4-win-x64.zip`, распакуйте архив целиком и запустите `Zapret.Desktop.exe`. Поддерживается Windows 10/11 x64; отдельная установка .NET не требуется. Перед ручной заменой экспортируйте пользовательские данные, сохраните собственные изменения в `zapret/lists` и полностью закройте приложение.

Проверка выпуска: 233 теста Core и 116 тестов Desktop, включая headless GUI; интерфейс проверен в светлой и тёмной темах. В архив включены Flowseal zapret 1.10.4 и уведомления о лицензиях. Дистрибутив zapret обновляется отдельно через настройки приложения.
