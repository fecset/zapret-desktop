# Zapret Desktop 0.2.4

- В разделе обновлений теперь кнопки с подписями. Перед установкой видно, что приложение перезапустится.
- Кнопка «Что нового» открывает описание выбранного обновления — отдельно для zapret и Zapret Desktop. Убраны повторяющиеся статусы, исправлены отступы и читаемость текста в тёмной теме.
- При дальнейших обновлениях приложения установленная версия zapret сохраняется. Его можно обновлять отдельно, когда это нужно.
- После обновления zapret служба Windows использует новые параметры выбранной стратегии.
- После перезапуска отображается результат установки. При сбое установщик пытается снова открыть приложение.

## Обновление

Откройте «Настройки → Обновления» и нажмите кнопку обновления Zapret Desktop.

Для ручной установки скачайте `ZapretDesktop-v0.2.4-win-x64.zip` и распакуйте архив целиком. Перед заменой старой версии экспортируйте пользовательские данные, сохраните свои изменения в `zapret/lists` и закройте приложение через меню трея → «Выход».

Windows 10/11 x64. Устанавливать .NET отдельно не нужно. В комплекте — zapret 1.10.4.
