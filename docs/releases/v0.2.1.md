# Zapret Desktop 0.2.1

- Исправлен автоподбор после обновления Flowseal: адаптированный скрипт теперь встроен в приложение и не заменяется при обновлении дистрибутива. Стратегии и цели проверки читаются из текущей папки `zapret`.
- Проверка доступности YouTube и Discord больше не блокирует остановку, перезапуск или выбор стратегии. При остановке и перезапуске устаревшие проверки отменяются, а их результаты не отображаются.
- Повторные команды запуска и остановки не накапливаются в очереди. Кнопки управления недоступны только на время изменения состояния движка; ожидание сети их не блокирует.
- Сохранены отмена автоподбора, восстановление исходного IPSet и очистка временного тестового скрипта. Добавлены регрессионные и headless GUI проверки этих сценариев.
- Встроенный дистрибутив обновлён до официального Flowseal zapret 1.10.4: включены его стратегии, списки и новые фейковые пакеты.

Скачайте `ZapretDesktop-v0.2.1-win-x64.zip`, распакуйте архив целиком и запустите `Zapret.Desktop.exe`. Поддерживается Windows 10/11 x64; отдельная установка .NET не требуется.

Для обновления закройте приложение через трей → «Выход». При ручной замене папки предварительно экспортируйте пользовательские данные и сохраните свои изменения в `zapret/lists`.

Проверка выпуска: 166 тестов Core и 46 тестов Desktop, включая headless GUI. В архив включены Flowseal zapret 1.10.4 и уведомления о лицензиях; дистрибутив Flowseal можно обновить отдельно через настройки приложения.
