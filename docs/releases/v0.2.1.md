## Zapret Desktop 0.2.1

- Исправлен сброс прокрутки при действиях, обновлении статуса и сохранении темы. Переход в другой раздел открывает страницу сверху.
- Исправлена страница стратегий: вся страница прокручивается, длинная сводка истории ограничена по высоте, подробный отчёт раскрывается отдельно. Результат можно скрыть.
- Убраны ручное сравнение SHA-256 и выбор технического имени ACTIVE payload из настроек. Кнопки отмены замены для Discord и игр показываются только для изменённых файлов с сохранённым оригиналом.
- Сетевые списки и hosts вынесены из установки обновлений в отдельный блок. Объяснены предпросмотр, применение и дальнейшая проверка соединения; кнопка применения hosts больше не выглядит как удаление.
- После применения hosts обновляется диагностика. Альтернативные адреса YouTube/Discord не считаются ошибкой; записи с локальными или нулевыми адресами по-прежнему отмечаются как блокирующие. Повторяющиеся записи не дублируются в отчёте.
- Релиз содержит только ZIP. Проверка SHA-256 остаётся внутри CI и проверки обновлений; отдельный файл контрольной суммы не публикуется. Временные файлы упаковки создаются вне `dist`.

Скачайте `ZapretDesktop-v0.2.1-win-x64.zip`, распакуйте целиком и запустите `Zapret.Desktop.exe`. Установка .NET не требуется. Перед переходом экспортируйте пользовательские данные; редактируемые файлы внутри старого каталога приложения не переносятся при ручной распаковке нового ZIP.
