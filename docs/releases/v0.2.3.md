# Zapret Desktop 0.2.3

- Обновления zapret и Zapret Desktop устанавливаются из «Настроек → Обновления» одной кнопкой. При обновлении zapret приложение само останавливает и перезапускает Zapret; Desktop после установки запускается снова.
- Во время загрузки показываются этап, объём и прогресс; подготовку можно отменить.
- На главной появилась карточка с доступными версиями и ссылкой «Что нового», а версии zapret и Desktop отображаются в боковом меню.
- Кнопки обновления заменены компактными иконками; после установки статус показывает актуальную версию.

Скачайте `ZapretDesktop-v0.2.3-win-x64.zip`, распакуйте архив целиком и запустите `Zapret.Desktop.exe`. Поддерживается Windows 10/11 x64; отдельная установка .NET не требуется.

Для обновления закройте приложение через трей → «Выход». При ручной замене папки предварительно экспортируйте пользовательские данные и сохраните свои изменения в `zapret/lists`.

Проверка выпуска: 230 тестов Core и 107 тестов Desktop, включая headless GUI. В архив включены Flowseal zapret 1.10.4 и уведомления о лицензиях; дистрибутив Flowseal можно обновить отдельно через настройки приложения.
