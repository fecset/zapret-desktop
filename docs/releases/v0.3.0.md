# Zapret Desktop 0.3.0

- Полностью обновлён интерфейс: главная страница со статусами движка, драйвера и службы, единые блоки и отступы во всех разделах, светлая и тёмная темы.
- Проверка YouTube и Discord показывает ход проверки, время ответа и ошибки. Результаты можно раскрыть для подробностей. HTTPS-проверка не подтверждает воспроизведение видео и голосовую связь.
- Исправлены выравнивание кнопок, рамки клавиатурного фокуса и изменение размера окна. Оконные кнопки используют Fluent Icons. После остановки Zapret фон статуса также становится нейтральным. Новый логотип используется в приложении, на панели задач и в трее.
- В настройках автозапуска Windows появился пункт «При автозапуске сворачивать окно в трей». При ручном запуске окно открывается как обычно.

## Обновление

Откройте «Настройки → Обновления» и обновите Zapret Desktop. Установленная папка `zapret`, пользовательские списки и настройки сохраняются.

Для ручной установки скачайте `ZapretDesktop-v0.3.0-win-x64.zip` и распакуйте архив целиком. Перед заменой старой версии экспортируйте пользовательские данные, сохраните свои изменения в `zapret/lists` и закройте приложение через меню трея → «Выход».

Windows 10/11 x64. Устанавливать .NET отдельно не нужно. В комплекте — zapret 1.10.4.
