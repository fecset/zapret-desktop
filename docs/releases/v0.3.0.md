# Zapret Desktop 0.3.0

- Обновлён интерфейс всех разделов, светлая и тёмная темы.
- Добавлено сворачивание приложения в трей при автозапуске Windows. При ручном запуске окно открывается как обычно.
- Исправлены выравнивание кнопок и отображение статуса после остановки Zapret.
- Обновлён значок приложения, включая панель задач и трей. После установки обновления Windows перечитывает значок в Проводнике.
- После успешного обновления Desktop папка предыдущей версии автоматически удаляется.

## Обновление

Откройте «Настройки → Обновления» и нажмите кнопку обновления Zapret Desktop.

Для ручной установки скачайте `ZapretDesktop-v0.3.0-win-x64.zip` и распакуйте архив целиком. Перед заменой старой версии экспортируйте пользовательские данные, сохраните свои изменения в `zapret/lists` и закройте приложение через меню трея → «Выход».

Windows 10/11 x64. Устанавливать .NET отдельно не нужно. В комплекте — zapret 1.10.4.
