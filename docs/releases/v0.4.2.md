# Zapret Desktop 0.4.2

Исправления надёжности, защиты пользовательских данных и интерфейса.

- Обновление IPSet и замена payload через `service.bat` теперь сначала готовят и проверяют отдельный файл. Ошибка загрузки или записи сохраняет прежний рабочий файл.
- Самостоятельный тест стратегий надёжно сохраняет IPSet и маркер восстановления. Ошибки тестирования передаются приложению; прежние процессы перезапускаются только после успешного восстановления данных.
- Диагностика в `service.bat` больше не останавливает и не удаляет сторонние службы автоматически.
- Автоподбор не рекомендует стратегию, если ни одна проверка не была успешной. Исправлено определение режима IPSet для списков со служебной строкой и пользовательскими адресами.
- При изменении ширины окна сохраняется несохранённый ввод в настройках Telegram-прокси и на странице списков.
- Ошибки остановки прокси и открытия Telegram из трея обрабатываются без блокировки дальнейших действий.
- После отката zapret обновляется команда установленной службы. Копирование и проверка файлов при установке и откате выполняются вне потока интерфейса.
- Вытесненные и отменённые планы обновлений освобождаются; при штатном выходе очищаются незавершённые подготовленные данные. План установки Desktop сохраняется до передачи помощнику.
- Проверка комплектности дистрибутива и упаковка учитывают `cygwin1.dll`.
- Для разработки ограничено накопление завершённых UI-preview; из новых preview-сборок исключены крупные нативные PDB-файлы.

## Обновление

Откройте «Настройки → Обновления» и обновите Zapret Desktop.

Для ручной установки скачайте `ZapretDesktop-v0.4.2-win-x64.zip` и распакуйте архив целиком. Перед заменой старой версии экспортируйте пользовательские данные через «Настройки → Резервные копии и перенос данных» и закройте приложение через меню трея → «Выход».

Изменения в самостоятельных `service.bat` и `utils/test zapret.ps1` входят в дистрибутив этого ZIP. Помощник обновления Desktop сохраняет уже установленную папку `zapret` целиком; чтобы получить новые BAT/PowerShell-скрипты при переходе с предыдущего выпуска, используйте полную ручную установку ZIP с переносом данных.

Windows 10/11 x64. Устанавливать .NET отдельно не требуется.

## Проверка

600 автотестов в конфигурации Release: инфраструктура и данные — 298, интерфейс — 245, Telegram-прокси — 57. Проверены файловые отказы и восстановление на временных данных, сохранение ввода при изменении размера окна, ошибки выхода и локальные сетевые сценарии Proxy.

Реальные UAC, установка служб, обход DPI, работа Telegram Desktop с аккаунтом, видео и звонки требуют отдельной проверки в пользовательской среде.
