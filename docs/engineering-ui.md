# Engineering dashboard

Интерфейс перенесён из финального FigCraft-макета «Zapret Desktop — Engineering dashboard» в существующий Avalonia `MainWindow`. Остальные разделы используют общую оболочку и сохраняют своё рабочее содержимое.

## Реализация

- `src/Zapret.Desktop/Styles/Engineering.axaml`: 25 семантических цветов для Dark/Light, шрифт и состояния контролов.
- `EngineeringTheme.cs`: общие размеры и соответствия ресурсам штатных контролов Fluent 12.1.3.
- `MainWindow.cs`, `WindowChrome.cs`, `WindowCaptionIcon.cs`: навигация, непрозрачная строка окна без подписи, оконные значки Fluent UI System Icons 16 Regular в общих слотах 16×16, зоны изменения размера и сохранение способа фокусировки.
- `HomeView.cs`, `EngineeringSection.cs`: общая рамка основных блоков всех страниц и единый внутренний отступ 20 px. Внутренние карточки стратегий используют простые рамки.
- Статус внизу боковой панели: точка и надпись центрированы в общей строке с высотой текста 18 px.
- `ActionButton.cs`: явно центрированные подписи и содержимое кнопок, единая высота стандартных действий 44 px.
- `BrandMark.cs`, `Assets/app.svg`, PNG и ICO: новый монохромный знак во всех ресурсах приложения. Окно и трей используют один источник иконки; тот же ICO встроен в EXE. Растровые версии воспроизводятся командой `python scripts/Build-AppIcon.py` с Pillow.
- `FeatureViews.cs`: реальные HTTPS-результаты, раскрытие URL/HTTP/ошибки, Escape.
- `FeatureViewModel.cs`: отображаемая ошибка неудачной проверки; отменённые и устаревшие операции не публикуют новую ошибку.
- `Assets/Fonts`: локальные JetBrains Mono Regular/Medium, включая кириллицу. Лицензия в `licenses/JetBrainsMono-OFL.txt`.

Активная стратегия берётся из фактического статуса. Выбор следующего запуска её не подменяет. Неизвестное состояние, внешний процесс и отсутствие службы представлены отдельно. По уточнённому образцу пояснения стратегии находятся слева, селектор справа; кнопка применения расположена отдельно под карточкой слева. Далее идут заголовок «Быстрые действия», две карточки действий и фактические версии/время запуска.

Автозапуск 0.3.0: `DesktopSettings.StartInTray` и `SettingsDraft` хранят выбор скрытого старта. Вложенная галочка видна только при включённом запуске с Windows. Планировщик передаёт `--autostart`, аргументы сохраняются при повышении прав. `WindowStartup` скрыто инициализирует окно и движок; обычный запуск показывает окно. Поле поддерживается в экспортируемых настройках.

## Воспроизводимая визуальная проверка

```powershell
$env:ZAPRET_UI_SCREENSHOTS = Join-Path $PWD 'TestResults/engineering-ui'
dotnet test tests/Zapret.Desktop.Tests/Zapret.Desktop.Tests.csproj -c Release --filter FullyQualifiedName~EngineeringDashboardTests
```

Тесты используют настоящий `MainWindow` и Skia, временный дистрибутив и существующие подменённые службы. Снимки содержат тестовые PID/результаты. В рабочее приложение демонстрационные данные не добавлены.

Покрыты обе темы, 1440×900 и 1200×800, изменение размера, масштаб 125/150/200%, клавиатурный фокус, Escape, раскрытия, меню стратегий, ожидание перезапуска, остановленное состояние, отсутствие проверки, процесс проверки, частичный/успешный/ошибочный результат и повторная проверка. Дополнительно проверены hover/pressed/disabled/loading, сохранение мышиного/клавиатурного способа фокусировки и отсутствие стандартной чёрной обводки. Центры и толщина оконных значков проверяются по отрисованным пикселям при разных DPI. Существующие UI-тесты продолжают проверять действия остальных разделов.

Нативное окно Windows с теми же безопасными службами:

```powershell
.\scripts\Preview-EngineeringUi.ps1
.\scripts\Preview-EngineeringUi.ps1 -Light -Compact
.\scripts\Preview-EngineeringUi.ps1 -Large
```

Этот режим включается только отдельным параметром сборки `UiPreview`; обычное приложение и штатный тестовый запуск его не используют. Он не требует UAC и не управляет установленным Zapret. Закрытие окна удаляет временные файлы тестового окружения.

Открываются два окна: панель «Состояния интерфейса» и настоящий интерфейс приложения. В панели можно независимо выбрать 13 состояний Zapret, 7 результатов соединения, 14 статусов обновления, тему и размер. Кнопка «Показать состояние» пересоздаёт временное окружение. Флажок «Сразу открыть раздел обновлений» показывает подробности загрузки и установки. По умолчанию окно 1200×800; `-Large` выбирает 1440×900. В самом приложении доступны навигация, раскрытия и кнопки запуска/остановки тестового движка. Проверка соединения в процессе имеет обычный тайм-аут 10 секунд; её можно повторить. Реальная установка Desktop отключена, результаты установки выбираются в панели. Версии обновлений, PID и сетевые результаты являются примерами.

`PreviewGalleryTests` открывают все варианты в обеих темах и проверяют повторное открытие, отмену незавершённых операций, запуск/остановку и независимое закрытие окна приложения.

## Отличия от статического макета

По уточнённым требованиям верхняя системная полоса убрана, а над прокручиваемой областью выделена отдельная непрозрачная строка. Растеризация шрифтов и полоса прокрутки зависят от Windows и масштаба. Технические сведения включают все фактически возвращённые данные, поэтому длинные сообщения и названия могут увеличивать высоту блоков. Дополнительные действия и реальные данные остальных разделов сохранены; они не заменены каркасами макета. Проверка реальных сетевых соединений, службы, драйвера и UAC не входит в визуальную проверку с моками.
