# Завершение замечаний review и релиз 0.2.0

Основание: пользователь поручил исправить все оставшиеся пункты отчёта, выполнить тесты, опубликовать изменения и release на GitHub. Ранее исправленные P1 входят в релиз.

## Объём и решения

1. Исправить четыре P2: снимок логов при экспорте и обработка ошибки записи; устойчивость к неполной поставке; специальные символы в пути при строгом разборе BAT; обновление результатов быстрой диагностики.
2. Добавить резервные копии и ZIP экспорт/импорт пользовательских настроек, списков, фильтров и изменённых payload; восстановление выбранной копии и исходных ACTIVE payload с SHA-256. Изменения файлов выполняются при остановленном движке и вне теста; импорт валидирует пути и объём.
3. Добавить проверку HTTP/TLS доступности YouTube и Discord, показывать время и результат отдельно от состояния winws. Добавить DNS, hosts, proxy и конфликты в диагностику; изменения системных файлов только явным действием после предпросмотра.
4. Сохранять историю автоподбора и подробный текст отчёта, показывать её в UI, позволить явное применение рекомендации.
5. Управляемые обновления: проверка и загрузка фиксированных upstream источников, проверка архива, резервная копия, сохранение пользовательских данных и откат. Desktop обновляется через отдельный локальный помощник после выхода; upstream и IPSet обновляются при остановленном движке. Предпросмотр hosts и отдельное явное применение.
6. Windows CI: restore, Release build, tests, PowerShell syntax, packaging; tag workflow публикует ZIP, checksum и release notes только после проверок. Локально проверяется структура поставки, версии и лицензии.

## Ответственность и параллельность

| Работа | Файлы | Проверка |
| --- | --- | --- |
| P2, UI, интеграция, версия и публикация | Desktop, StrategyProvider, Distribution, SettingsStore, README | Regression, UI smoke, полная сборка и tests |
| Резервные копии/payload | новые DataProtection contracts/services/tests, FakePayloadService | Round trip, rollback, Zip Slip, hashes, missing bin |
| Обновления/CI | новые ManagedUpdate contracts/services/tests, workflows, scripts | Архивы, URL, сохранение данных, rollback, упаковка |
| Диагностика/история | новые Health/History contracts/services/tests, DiagnosticService | Fake HTTP/DNS, persistence, повреждённые отчёты |

Новые контракты размещаются в отдельных файлах по домену, чтобы исключить параллельное редактирование Contracts.cs. Desktop интегрируется после стабилизации этих контрактов. Агенты не меняют Desktop, общий csproj, не коммитят, не пушат и не запускают настоящие драйверы или службы.
