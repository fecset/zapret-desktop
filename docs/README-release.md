# Zapret Desktop

Приложение для управления Zapret в Windows 10/11 x64. Устанавливать .NET отдельно не требуется.

Версия Desktop: 0.4.0.

## Первый запуск

1. Распакуйте весь ZIP в отдельную постоянную папку. Оставьте папку `zapret` рядом с `Zapret.Desktop.exe`.
2. Запустите `Zapret.Desktop.exe` и подтвердите запрос прав администратора: они необходимы для работы приложения.
3. На странице «Стратегии» выберите стратегию, затем нажмите «Запустить». Проверьте нужные вам сайты и приложения: подходящая стратегия зависит от провайдера.
4. Если соединение не работает, остановите Zapret и попробуйте другую стратегию или «Автоподбор». Перед тестом выполните показанные приложением условия. Во время автоподбора диагностика и списки временно недоступны; дождитесь окончания или отмените тест.

## Автозапуск Windows

В разделе «Настройки → Приложение» включите «Запускать приложение вместе с Windows». Под ним появится пункт «При автозапуске сворачивать окно в трей». Сохраните настройки. Для автоматического запуска выбранной стратегии включите также «Запускать Zapret при открытии приложения».

Сворачивание в трей действует при входе в Windows; ручной запуск показывает окно. Открыть скрытое окно можно через значок в трее.

## Обновление и ваши данные

Перед ручной заменой приложения откройте «Настройки → Резервные копии и перенос данных» и нажмите «Экспорт ZIP». Сохраните архив вне папки приложения.

Полностью закройте Desktop через меню значка в трее → «Выход». Если используете службу Zapret, сначала остановите её в настройках. Распакуйте новую версию целиком в отдельную папку. Для переноса настроек, списков, фильтров и payload используйте «Импорт ZIP» и следуйте подтверждениям приложения.

Сохранение изменённых фильтров при работающем Zapret может потребовать перезапуска: приложение покажет уведомление. Кнопка «Применить и перезапустить Zapret» применяет выбранные значения.

Импорт и восстановление не создают новую резервную копию. Если хотите сохранить текущее состояние, сначала нажмите «Создать копию». Отсутствующие в архиве файлы и настройки сохраняются; пустые пользовательские списки не стирают ваши текущие записи.

Если вы добавили в `zapret/lists` файлы с собственными названиями, скопируйте их отдельно: экспорт поддерживает стандартные списки, `list-custom.txt` и `ipset-custom.txt`.

## Если возникла проблема

- «Диагностика» показывает состояние компонентов и возможные конфликты; подробности действий доступны на странице «Логи».
- Если автоподбор был прерван и приложение просит восстановить IPSet, используйте выбранную резервную копию или импорт ранее экспортированного ZIP. До восстановления запуск будет недоступен.
- Перед изменением системного hosts проверьте предпросмотр. Если адреса уже совпадают, повторное применение не требуется.
- Для полного выхода используйте меню трея → «Выход». При включённом сворачивании в трей закрытие окна оставляет приложение работающим.

Описание изменений этой версии находится в `RELEASE_NOTES.md`. Сообщить об ошибке: [GitHub Issues](https://github.com/fecset/zapret-desktop/issues). Укажите версию Desktop, версию Windows, действия перед ошибкой и относящиеся к ней строки журнала.

## Telegram прокси

Откройте раздел Telegram прокси → Запустить прокси → Открыть в Telegram. Сервер слушает только 127.0.0.1:1443; если порт занят, измените его в настройках прокси и сохраните. Ключ показан в карточке подключения и защищён Windows DPAPI при хранении. Круговая стрелка справа обновляет ключ; после этого подключите Telegram заново. Автозапуск отключён по умолчанию. При полном выходе Desktop прокси останавливается, при сворачивании в трей продолжает работать. Запуск и остановка Zapret независимы от прокси.
